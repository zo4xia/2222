⚙ 配置映射 · 填关键参数 / 一键导入 JSON（第 4、5 步：换题或对接时用，日常播放看上面 1→2→3）
JSON 只要含 rows：[{stage, mp3, duration(秒), speech, board:{startDelay,startCoord,content}, actionSpec}]；多的字段忽略。
每个字段是干嘛的（照抄就行）
stage这一段是哪个环节：题目 / 分析 / 解答 / 总结（填错不显示）
mp3这一段的配音网址。没配音就空着写 ""，页面自动走无声时钟
duration这一段播多少秒，数字，如 14.6
speech这一段念的话，字幕也显示它
board.startDelay这一段开始后几秒才下笔，如 1.5
board.startCoord（可选，不写也行）下笔位置，格式 "[8%, 44%]"（横%, 竖%）。不给的话自动落在本环节区域左上角，四区照样板开
board.content板书写什么。一行一个，写完一个再写一个（可直接给数组，或用 \n 换行）。乘写 x、除写分数 \frac{3}{4}（不写 ÷）、平方写 ²、立方写 ³、三角形写"三角形"三个字
actionSpec这一段要强调就放这里。动作 1.0 三动作（夏夏拍板，颜色统一红）：圈字 {tool:"rough-notation",action:"circle",target:{exactText:"要圈的字"}}、下划线同理改 "underline"、横线 rough-line（白名单真源 boardToolCatalog；highlight/箭头已砍）。必须锚定已写出的文字（exactText）
actionSpec[].triggerKeyword（可选，★ Task 43）口播触发词：与 action 平级写在每项外层（不写在 action 内部），如 { "triggerKeyword":"5吨", "action":{...} }。填了它，动作会在口播念到这个词的时刻起笔；必须是本段 speech 里逐字存在的原文，填错则该动作退回板书写完后串行。一行内不许两处同时动，早了程序自动顺延，无需填任何时长
