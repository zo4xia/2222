# 教学板书 · 小学数学讲题视频生成工作台 —— 用户说明书

> 写给完全不懂技术的你：一位想把数学题变成讲解视频的小学老师，或教育机构的课程同事。
> 不需要会编程，会打字、会点鼠标就够了。跟着做，五分钟拿到你自己的讲题视频。

---

## ① 这个产品能帮你做什么

**一句话：你把一道小学数学题贴进来，AI 帮你把"讲什么、写什么板书、什么时候画重点"全部备好，你在播放页一键录制成一段带配音、带手写板书、带字幕的讲解视频。**

先讲三个真实的使用场景，看看是不是你：

**场景一：王老师，明天要交 3 个班的讲解视频**
以前她得举着手机对着作业本讲一遍又一遍，讲到嗓子哑。现在她把题目文字复制进来，等一杯茶的功夫，AI 就写好了分步讲稿和黑板板书。她戴上耳机试听一遍，把不满意的一句话改了改，点几下按钮，三道题各录一段，半小时不到全部交差。

**场景二：李老师，学生拍来的题目照片**
家长在群里发来一张练习册照片问怎么做。李老师把照片传进工作台，AI 自动认出题目、把它"贴"到黑板对应的位置，生成的视频里题目原图就摆在画面上方的"题目区"，配合下方一步步板书讲解，直接转发给家长。

**场景三：张校长，想给机构所有老师统一讲法**
机构的视频要风格统一。每位老师只负责贴题和最后把关，讲稿措辞、板书布局、重点圈画全部由系统按同一套规范生成；讲得不对的地方老师直接在表格里改字。录出来的视频直接交给剪辑同事进流水线。

屏幕上偶尔会看到 "Agent A / Agent B / Check Agent" 这样的字样，别慌——这就是三位幕后小助手的工号：

- **Agent A · 识题小助手**：负责认题、把题贴上黑板；
- **Agent B · 备课小助手**：负责写讲稿、排板书、标重点；
- **Check Agent · 审稿小助手**：负责把讲稿和板书再顺一遍，挑毛病。

## ② 五分钟上手：从贴题到拿到视频

### 开始前

用浏览器（推荐 Chrome 或 Edge）打开工作台网址——技术同事帮你装好后，地址一般是以 `localhost:3000` 结尾的，直接问他要就行。打开后页面最上方写着 **"✏️ 教学板书"** 和 **"第 1 步 · 生产车间"**，就说明来对地方了。

右上角的 **"全屏画布预览"** 和 **"本页 Agent 配置"** 两个按钮先不用管：前者是看大黑板用的，后者是技术同事填服务账号用的。

### 第 1 步：把题贴上黑板

**屏幕上会看到什么**：左边一张"创建一道题"卡片，里面有：

- 一个大输入框，提示文字写着 **"支持文本输入；也可上传图片识别后落到这里"**
- 三个小选项：**题目类型**、**板书侧重**、**参考年级**
- 一个 **"上传题目图片"** 按钮（图片题用它）
- 一个绿色按钮 **"识别并贴上画布"**（现在还是灰的，点了没反应）
- 中间是一块空白的小黑板缩略图，下面提示 **"初始是空白甲方画布。贴题后，题目直接放上去。"**

**你做什么**：

1. 把题目打字进大输入框（或者点"上传题目图片"传一张题目照片）；
2. 点 **"识别并贴上画布"**。

**会发生什么**：等十几秒，AI 把题目认出来——题目文字出现在小黑板上方的"题目"小标签下面；"参考年级"自动帮你填好（比如"2-6年级"）；灰色的"识别并贴上画布"重新亮起变绿，下面一排按钮也跟着醒来；提示语变成 **"看缩略画布：识别对不对、放位对不对。不好就重新生成。"**

**顺手检查一下**：题目认得对不对？年级合不合适？不对就改一下再点一次"识别并贴上画布"，或点小黑板上方的 **"重新生成落位"**。

> 可选小甜点：点 **"抽取知识小便签"**，AI 会为本题生成 3~6 张"解题秘籍小纸条"，页面底部会显示"将携带 N 张解题小纸条交给 Agent B"——带着小纸条去备课，讲得更细。

确认无误后，点右下角的绿色大按钮 **"确定进入生成表"**。

### 第 2 步：AI 备课，写讲稿和板书

**屏幕上会看到什么**：新页面（叫"生成 · Agent B 五字段"），最上面一排进度小票：**识别题目 ✓ 判断题型 ✓ 画布排版 知识关联 ✓ 组装输入 ✓ 待发送生成**——都是给你安心的"体检单"。左上角的返回箭头可以随时回第 1 步。

下面两张卡片：

- **"输入交接台"**：第 1 步的识别结果都在里面（三个小标签页：📊 配比提示 + 参数信息 / 📦 交接元数据 / 💡 题目分析 + 知识点）。新手不用细看，知道题没认错就行。
- **"五字段执行表"**：这才是主车间。刚进来时表格还是空的，中间写着"📐 题目信息与四区排版已就绪"，正中有个大按钮 **"开始生成五字段执行表"**（和这张卡片右上角的"生成五字段"是同一个功能，点哪个都行）。

**你做什么**：点深绿色大按钮 **"生成五字段"**（或点表格中间的"开始生成五字段执行表"）。

**会发生什么**：等半分钟到一分钟，表格里出现约 10 行——每一行就是这节课的一小段。列从左到右是：

| 列名 | 里面是什么 |
|---|---|
| 排序 | 一行的序号和拖动把手（提示"按住鼠标拖拽此行调整顺序"） |
| 教学环节 | 这一段属于：题目 / 分析 / 解答 / 总结（点环节名可改） |
| 演播室口播稿 | 老师念的话，底下标着"52 字 · 预估 21 秒" |
| 课堂同步板书 | 黑板上写的内容，有的行标着"+2.5s"（念了 2.5 秒后才动笔） |
| 板书动作 | 要圈、要画下划线、要画横线的强调动作 |
| 行操作 | 上移 / 下移 / 加一行 / 删一行四个小图标 |

顶上的"生成五字段"按钮变成了 **"重新生成"**（注意：重新生成是让 AI 重新创作，讲法用词会变，不是原样复制）。

**两个可选的润色按钮**（都在表格上方）：

- **"ASR 优化"**：把讲稿里的数学读法捋顺（分数、平方、括号怎么念更自然）。如果本来就很好，它会告诉你"当前口播稿已全部符合数学自然读音规范，无需调整"。
- **"Check Agent"**：请"审稿小助手"挑一遍毛病。挑出来的会列成清单，每条都摆着"原文 / 修正后"对比，你自己拿主意：点 **"保留原文"** 不改，或点 **"应用 N 处修改"** 全采纳。

**给每一段配音（强烈建议做）**：在每一行的口播稿下面点 **"生成语音"**。等几秒，"预估 21 秒"会变成 **"真实音频 11.9 秒"**，旁边多出 **"试听"** 和 **"播放预览"** 两个按钮，下方还有一条"🎵 本地音频:…"。不配音也能往下走，只是视频会全程静音。

> 小提醒：一行一配。嫌麻烦可以先把最重要的几行配上，试听完满意再补齐。

**最后**：点深绿色按钮 **"🎬 演播录制"**——浏览器会打开一个新标签页，这就是你的"演播室"。

### 第 3 步：播放页——试看、微调、录制

**屏幕上会看到什么**：新页面标题带"仿人板书微课"，主体是一块横版大黑板（米白纸底、浅蓝色贴纸边框），左上角"题目"标签，题目原文摆在题目区。底部一条工具栏：

> **「1 ▶ 播放」「2 ✍ 批注」「3 ● 录制」「4 📐 调整布局」** + 进度条 + 时间（形如"0.00 / 175.45 s"） + 最底下一行字幕

**先播放试看**：

1. 第一次打开时，"播放"按钮可能先显示 **"⏳ 字体加载中…"**——这是在下载手写体字库，**等它变成「1 ▶ 播放」再点**；
2. 点 **"1 ▶ 播放"**：配音响起（前提是配过音）、字幕跟着滚动、板书一句一句、一个字一个字地写出来，讲到重点还会用红笔圈、画下划线——像真人在黑板前讲课。按钮同时变成"⏸ 暂停"，再点一下就暂停；
3. 拖动进度条可以前后跳着看。

**录制视频**（满意之后）：

1. 把进度条拖回最左边；
2. 点 **"1 ▶ 播放"**；
3. 点 **"3 ● 录制"**——按钮变成 **"■ 停止并下载"**，录制开始（画面、板书、配音、字幕，全都在里面）；
4. 讲完（或你想停的任何时候）点 **"■ 停止并下载"**——浏览器自动把视频下载到你的"下载"文件夹，文件名是这节课的项目编号，后缀是 `.webm`。

> 想边讲边圈重点？先点 **"2 ✍ 批注"**（按钮变成"✍ 批注中(点停)"），鼠标变成十字，直接在画面上画圈画箭头——画的东西会一起录进视频。注意：批注画上去没法单独擦掉，刷新页面才恢复干净画面。

到这里，你已经拿到视频了。下面回答"不满意怎么办"。

## ③ 生成结果不满意怎么办

先别急着推倒重来。播放试听一遍，判断是哪类问题，对症下药——**微调三板斧**：

### 板斧一：改讲稿（话说得不对/不像你的风格）

回到第 2 步的表格，**直接在那一行的口播稿框里改字**，字数和预估秒数会跟着自动更新。

- 改完之后如果这一行已经配过音，**要再点一次该行的"重新生成"**（小提示：它的用途是"用最新口播内容重新配音"，旧音频不会自动更新）；
- 想让整节课换个讲法：点表格上方的 **"重新生成"**。小诀窍：普通点一下时，同一道题会直接沿用上次备课结果（很快，但内容不变）；**按住 Shift 再点**才是让 AI 强制重新备一版，讲法用词才会变。

板书也一样改：点那一行的 **"点击编辑板书"**，出现编辑小卡片——上面是板书内容输入框，下面是 **"落笔延迟（秒）"** 数字框（写着"本行语音开始播放后，延迟多少秒才动笔写板书（0 = 语音一起笔）"），改完点 **"完 成"** 收起。

### 板斧二：拖板书贴纸（只是位置看着别扭）

讲稿没问题，就是某句板书贴的位置不顺眼？去播放页拖一下：

1. 点 **"4 📐 调整布局"**——视频自动暂停（这是特意设计的，方便你安心摆画面）；
2. 每一句板书都变成了一个浅蓝色虚线小框（贴纸），画面顶部出现提示 **"拖句子贴纸=每句板书挪位（双击贴纸=撤消本句）；拖蓝色四区框=整体自动重排；文字实时自适应"**；
3. 用鼠标把贴纸拖到想要的位置，松手。顶部提示会告诉你 **"第N句已落位（dx=…, dy=…px）——记得点「💾 保存布局」存档；双击贴纸可撤消本句"**；
4. 摆完点 **"💾 保存布局"**（提示"✅ 已保存当前手工调整的板书布局至本地存储！"），再点 **"✕ 完成退出"** 回到播放。

### 板斧三：调区框（想给整个区域挪窝/改大小）

还是这个微调模式里，有四个彩色大虚线框——**题目区（蓝）、分析区（橙）、解答区（绿）、总结区（紫）**，四个红色小框是黑板上"题/析/解/结"四个标签的位置：

- **拖框身**：整个区域搬家，里面的板书跟着自动重排；
- **拖框边上的小方块**：单独调宽、调高（提示"拖拽区域调整位置，拖拽右侧/下侧/角标调整宽度与高度，文字实时重排"）；
- 顶部勾着 **"磁吸 0.5%"** 的话，拖动时会自动对齐到细网格，摆得更整齐（不想要可以取消勾选）。

### 撤消方法（都有后悔药）

- **单句板书挪错了**：双击那个贴纸——提示"第N句已撤消手动位置，回到自动排版"；或者干脆把它拖回原位，也会回到自动排版；
- **全部不满意**：点 **"🔄 恢复预设"**——提示"已恢复标准默认四区排版（含清空每句手动挪位）"，一切归零重来；
- **拖出画布了**：顶部立刻出现红色警告（"⚠️ 越界警告：[区域名] 已超出 1726×980 画布！……请向内调整"），画布四周亮起红色警戒带，**松手后自动弹回安全位置**，不会弄丢任何东西。

## ④ 导出与后期

### 录制成视频（回顾一下）

播放页：进度条拖到头 → **"1 ▶ 播放"** → **"3 ● 录制"** → 讲完 **"■ 停止并下载"**。录进去的内容包括：黑板画面、一笔一笔的板书、红笔动作、字幕、配音，还有你批注模式下的现场手绘。

### 录出来是 webm，怎么变成 mp4？

`.webm` 是浏览器录制视频的标准格式，**剪映直接就能导入**，不用转换。想要 mp4：在剪映里剪辑完，导出时格式选 MP4 就行。OBS 等录屏剪辑软件也都认识 webm。实在打不开，把文件拖进浏览器窗口就能预播。

### 除了视频，还能导出什么？

都在第 2 步"五字段执行表"上方：

**"导出"下拉菜单里三样**：

| 菜单项 | 是什么 | 给谁用 |
|---|---|---|
| 口播稿件 MD（纯语音用） | 一份完整讲课文稿文件 | 配音同事、复习讲义 |
| 画布分镜总表 MD（导入剪辑器用） | 一行一拍的分镜表 | 剪辑同事对时间轴 |
| 完整规格 JSON（板书+时序状态树） | 一份完整的"视频工程档案"——这节课全部台词、板书、时间点的完整记录 | 剪辑师、技术对接；可以理解为"这节课的工程文件"，别人拿到它就能原样还原这节课 |

**"生成交付单页"按钮**（生成后按钮变成"固化归档"）：把本节课"定格"成一对永久文件——一个能直接打开看的网页单页，加一个同名的工程档案文件。完成后会弹一个窗口，写着"🎉 教学视频素材参数产物单页已生成"和这节课的**交付项目编号**，三个按钮任选：**"立即打开 HTML 产物单页"**（直接看成品参数页）、**"下载配套 JSON 文件"**（把工程档案存到本地）、**"留在当前页面"**（先不看）。

**播放页里的"📥 导出 JSON"**：在微调模式里点它，会把你手工摆过的板书布局也打进一份工程档案文件（提示"✅ 已下载微调后的交付 JSON 规格文件"）——想把这节课的排版带给别的电脑，就用它。

## ⑤ 常见问题 FAQ

**1. 打开播放页，没声音？**
按这个顺序查：① 看左下角按钮是不是还写着"⏳ 字体加载中…"——等它变成"1 ▶ 播放"再操作；② 浏览器有个规矩：必须先亲手点过页面才允许出声，所以一定要点一次"1 ▶ 播放"；③ 还没声，回第 2 步看那一行是不是"未生成音频"——没点过"生成语音"的行，天生就是静音的，去补配一下。

**2. 板书的字看着不像手写体，像普通宋体？**
手写体字库还没下载完。第一次打开（或刚清了浏览器缓存）会现下载字库，网络慢就多等几秒。只要等"⏳ 字体加载中…"变成"1 ▶ 播放"再播放，字就是漂漂亮亮的手写体了。

**3. 录出来的视频是 webm，我的播放器打不开？**
webm 是视频文件的一种格式。用剪映直接导入就能剪；或把文件拖进浏览器窗口就能播。要 mp4 就用剪映导出时选 MP4。

**4. 点了"● 录制"没反应？**
极少数情况（比如题目图是从别人网站链过来的），浏览器安全限制不让录。先关掉播放页重新打开再试；还不行就把题目截图重新上传一遍（自己传的图基本都能录）；再不行，找技术支持。

**5. 暂停后再点播放，怎么从这一句的开头讲起，而不是从暂停的那一秒继续？**
这是特意设计的：一行话就是一个"教学小单元"，从句头重播方便你反复听某一句，剪辑时也好截取。想跳到别处直接拖进度条。

**6. 拖好的板书位置，换了台电脑就没了？**
"💾 保存布局"只保存在**你这台电脑的这个浏览器**里，换浏览器、清缓存都会丢。重要版面记得点 **"📥 导出 JSON"** 把工程档案存成文件，换电脑时交给我们导入就能恢复。

**7. 改了讲稿/重新配了音，播放页里放的还是旧的？**
你看到的旧播放页是打开那一刻的"快照"。回第 2 步**重新点一次"🎬 演播录制"**，新开的标签页一定是最新内容。旧的播放页直接关掉。

**8. 板书里的除号怎么变成了分数样子？乘号怎么是个 x？**
这是板书书写规范，跟小学手写竖式的习惯保持一致：除法写成分数、乘号写成 x、平方写成 ²、立方写成 ³。接受不了的话，去那一行的"点击编辑板书"里改成你想要的写法。

**9. "生成五字段"要等多久？重复生成会变吗？**
一般 30 秒到 1 分钟，AI 在现场备课。同一道题再点一次"重新生成"会直接沿用上次结果（很快但没变化）；**按住 Shift 再点**才是强制重新备课，讲法用词会变。

**10. 想让 AI 换个讲法/换个难度？**
三个入口：改表格上方的"讲课风格"下拉；回第 1 步改"题目类型""参考年级"再重新生成；或直接在表格里点某一行的"教学环节"名（题目/分析/解答/总结四选一）改归类。

**11. 第 1 步识别错了怎么办？**
直接改题目文字再点"识别并贴上画布"；类型、年级也可以手动改；题目在小黑板上的位置不对就点"重新生成落位"。第 1 步多花 10 秒检查，比录完再返工划算得多。

**12. 播放页底部折叠的"⚙ 配置映射"是什么？**
那是给技术对接用的面板（它自己也标着"换题或对接时用，日常播放看上面 1→2→3"）。日常录课完全不用碰它。

**13. 批注画错了想擦掉？**
批注层没有橡皮擦。刷新播放页就是干净画面；录制前如果想保持画面干净，就别开着批注，或把批注留到你确定要画的重点上（它会随视频一起录进去）。

## ⑥ 什么时候该找技术支持

下面这些事不是你的问题，也不是说明书能解决的，直接找技术同事最省时间：

- **第一次安装和启动**：打不开网址、页面白屏、按钮全是灰的；
- **服务配置**：顶栏"本页 Agent 配置"和第 2 步的钥匙按钮里，识题、备课、配音三种服务的账号都没填/失效了（识别、生成一直转圈或报红字提示）；
- **"生成语音"点了没动静**，或生成的音频听不了；
- **"● 录制"反复失败**（刷新、换图都没用）；
- **批量生产需求**：一学期几百道题想批量出视频、想对接你们机构自己的剪辑或发布流水线（把导出的"完整规格 JSON"工程档案交给技术就能谈）；
- **备份与迁移**：想把这台电脑的课搬到别的电脑，或找回之前的项目；
- **导出的工程档案要对接着其他平台**用，但对方不知道怎么读。

找的时候带上三样东西：**题目原文、屏幕上的报错文字（截个图最好）、交付项目编号**（生成交付单页后弹窗里那串"deliverable-…"编号），技术同事会快很多。
