## 一、开发守则（10 条铁律）

### 1.1 主链路保护

1. **不动 A/B 主链路**：`contract.js` / `prompt.js` / `stepHandoff.js` / `service.js` / `timing.js` 不重构、不搬动、不替换。新增能力走独立插件、独立接口和独立配置。
2. **不删预设账号**：`userApiConfig.js` / `agentBApiConfig.js` / `checkAgentApiConfig.js` 默认值是用户预设的演示账号，禁止删除或重置。

### 1.2 真相优先级

3. **真相源分级**：运行时代码（`src/` + `server/`）> 文档 > 记忆。与代码冲突时一律以代码为准，并顺手订正文档与记忆。
4. **画布参数唯一真源**：`src/services/stepHandoff.js` 顶部常量 `CANVAS_SIZE / QUESTION_FONT_SIZE / BOARD_FONT_SIZE / QUESTION_LINE_HEIGHT / buildCanvasParams()`。任何文件需要这些值必须 `import`，再出现字面值 = bug。
5. **Agent B 提示词真源**：`src/agent-b-v2/prompt.js`（396 行）+ `skills/liyongle-elementary/`（7 段拼接）。禁止为省 token 删减教学内容。

### 1.3 工作流铁律

6. **改一测一**：每改完一个治理项，立即跑 `npm run lint` + `npm run check:proxy` + 浏览器手测。lint 通过 ≠ 验证通过，必须有运行时证据。
7. **dev 期不 build**：开发未完成的功能一律保持热更新（vite dev）。`vite.config.js` 的 build 入口已移除 lite-player.html，但开发期仍只跑 dev。本仓 dev 端口：3001 / 3200 / 5199（3000 是另一个项目，勿用）。
8. **禁境外资源**：禁止 Google Fonts / jsdelivr / unpkg / ImgBB 等国内不可达资源。UI 字体用本地系统栈；JS 库本地化到 `public/`。唯一例外：`fontsapi.zeoseven.com` 板书字体（用户指定）。
9. **变更留痕**：任何修改必须记录变更树到 `ENGINEERING_LOG.md`（背景/思路/执行步骤/代码变更/验证结果/接力棒），关键决策追加 `DECISIONS.md`（问题/方案/决策/理由/风险/验证/影响），实时更新 `PROJECT_STATE.md`。
10. **错误熔断**：一个问题错误超过 5 次马上停下，逆向思考断裂点。多视角模拟（用户视角、产品经理视角）找不合理点。

## 二、接口规范

### 2.1 统一请求格式

**请求**：
```http
POST /api/<resource>/<action>
Content-Type: application/json

{ "字段1": "值1", "字段2": "值2" }
```

**成功响应**：
```json
{
  "ok": true,
  "timestamp": "2026-09-17T...ISO",
  "requestId": "uuid-v4",
  ...业务字段
}
```

**失败响应**：
```json
{
  "ok": false,
  "code": "ERROR_CODE",
  "error": "人类可读的错误描述",
  "diagnostic": { ... },
  "timestamp": "2026-09-17T...ISO",
  "requestId": "uuid-v4"
}
```

### 2.2 错误码标准

| 错误码 | HTTP 状态 | 含义 |
|---|---|---|
| `INVALID_INPUT` | 400 | 请求体格式错误或字段缺失 |
| `UNAUTHORIZED` | 401 | API Key 无效或缺失 |
| `FORBIDDEN` | 403 | CORS / UPSTREAM_HOSTS 拒绝 |
| `NOT_FOUND` | 404 | 资源不存在 |
| `METHOD_NOT_ALLOWED` | 405 | 方法不支持 |
| `UPSTREAM_TIMEOUT` | 504 | 上游 LLM/TTS 超时 |
| `UPSTREAM_ERROR` | 502 | 上游返回非 200 |
| `PARSE_FAILED` | 422 | LLM 输出无法解析 |
| `INTERNAL_ERROR` | 500 | 服务器内部异常 |

### 2.4 前端调用规约

- 统一走 `src/services/apiClient.js` 封装（不直接 fetch）
- 默认超时 30s；长生成（B 生成）用 170s
- 错误处理：捕获 `err.code` 与 `err.statusCode`，按错误码分类提示
- Loading 三件套：`<QhLoading>` / `<QhEmpty>` / `<QhError>` / `<QhSkeleton>` 必备

### 2.5 后端中间件规约

- 统一走 `server/middleware.js` 的 `withMiddleware` 包装
- 静态文件服务必须用 `withSafeStatic`（带路径穿越校验）
- CORS 通过 `applyCors` 统一处理
- 错误响应通过 `sendJson` 统一格式

### 2.6 安全配置

```bash
# .env 必须配置
CORS_ORIGINS=https://your-frontend.com
UPSTREAM_HOSTS=api.openai.com,api.anthropic.com,api.fish.audio
FISH_AUDIO_API_KEYS=key1,key2  # 多 Key 轮询
NODE_ENV=production  # 生产环境必须
```

## 六、规范手册三页纸总结

> 本手册不超过三页，下一接手人员应能在 5 分钟内掌握项目规范。

### 第一页 · 铁律与禁区

- **不动 A/B 主链路**（contract / prompt / stepHandoff / service / timing）
- **不删预设账号**（userApiConfig / agentBApiConfig / checkAgentApiConfig 默认值）
- **dev 期不 build**，dev 端口 3001/3200/5199
- **禁境外资源**（仅 zeoseven 字体允许例外）
- **真相源分级**：代码 > 文档 > 记忆
- **画布参数唯一真源**：`src/services/stepHandoff.js`
- **区域命名统一**：question / analysis / solution / summary（禁用 topic）
- **变更必留痕**：PROJECT_STATE + ENGINEERING_LOG + DECISIONS 三件套

### 第二页 · 接口与命名

- **统一请求**：`POST /api/<resource>/<action>` + `Content-Type: application/json`
- **统一响应**：`{ ok: true/false, ...业务字段, timestamp, requestId }`
- **错误码标准**：INVALID_INPUT / UNAUTHORIZED / FORBIDDEN / NOT_FOUND / METHOD_NOT_ALLOWED / UPSTREAM_TIMEOUT / UPSTREAM_ERROR / PARSE_FAILED / INTERNAL_ERROR
- **前端调用**：走 `src/services/apiClient.js`，不直接 fetch
- **后端中间件**：走 `server/middleware.js` 的 `withMiddleware`
- **静态服务**：用 `withSafeStatic`（带路径穿越校验）
- **文件命名**：组件 PascalCase.vue / composable useXxx.js / 常量 UPPER_SNAKE_CASE
- **Git 提交**：`<type>(<scope>): <subject>` 规范

### 第三页 · 验证与部署

- **每次改动**：跑 `npm run lint` + `npm run check:proxy` + 浏览器手测全链路
- **dev 启动**：`npm run dev`（端口 3001）
- **生产启动**：`bun run start`（或 `npm run start`）
