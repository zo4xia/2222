## 一、环境准备（首次接手）

### 1.1 必装软件

| 软件 | 版本 | 用途 |
|---|---|---|
| Node.js | ≥ 20.x LTS | 运行 vite dev / productionServer |
| Bun | ≥ 1.2.x | 生产入口 `bun run start` |
| npm | ≥ 10.x | 依赖管理 |

### 1.2 安装依赖

```bash
cd /path/to/extracted
npm install
```

### 1.3 配置 .env（本机，不进 git）

复制 `.env.example` 为 `.env`，填入：


## 二、启动项目

### 2.1 开发模式（推荐）

```bash
npm run dev
# 应在端口 3001 启动
# 浏览器访问 http://localhost:3001
```

如果 3001 被占用，改用 3200 或 5199（修改 `vite.config.js` 的 `port` 字段，**禁用 3000**）。

### 2.2 生产模式

```bash
# 1. Build
npm run build
# 产物在 dist/

# 2. 启动生产服务器
bun run start
# 或：npm run start
# 应在端口 3000 启动（生产环境可用 3000）
```

### 2.3 部署到 Vercel

```bash
# 1. 安装 Vercel CLI
npm i -g vercel

# 2. 部署
vercel

# 3. 配置 Vercel Env
# 在 Vercel 后台配置：
# FISH_AUDIO_API_KEYS
# CORS_ORIGINS
# UPSTREAM_HOSTS
# NODE_ENV=production
```

## 四、常见问题排查

### 4.1 端口被占用

```bash
# 查看占用进程
lsof -i :3001  # Linux/Mac
netstat -ano | findstr :3001  # Windows

# 改用其他端口（3001 → 3200 / 5199）
# 修改 vite.config.js 的 port 字段
```

### 4.2 上游 LLM 超时

```bash
# 检查 .env UPSTREAM_HOSTS 是否包含目标域名
cat .env | grep UPSTREAM_HOSTS

# 检查网络
curl -I https://api.openai.com
```

### 4.3 TTS 合成失败

```bash
# 检查 Fish Audio Key
curl http://localhost:3001/api/tts/info
# 预期：{"ok":true,"keyCount":2,...}

# 如 keyCount=0，检查 .env FISH_AUDIO_API_KEYS
```

### 4.4 知识库加载失败

```bash
# 检查 doc/knowledge-a.compact.json 是否存在
ls -lh doc/knowledge-a.compact.json
# 预期：140KB

# 跑知识库自检
npm run check:knowledge
```

### 4.5 代理自检失败

```bash
npm run check:proxy
# 检查输出，定位失败项
```

## 七、关键约束速记

> 接手前必背，违反 = 抢跑

- ⛔ **不动 A/B 主链路**（contract / prompt / stepHandoff / service / timing）
- ⛔ **不删预设账号**（userApiConfig / agentBApiConfig / checkAgentApiConfig 默认值）
- ⛔ **不补 handdraw-player.html / lite-player.html**（用户明示不补回）
- ⛔ **不用 3000 端口验证本仓**（属另一个项目）
- ⛔ **不执行 vite build 验证未完成功能**（开发期只跑 dev）
- ⛔ **不引用境外资源**（Google Fonts / jsdelivr / unpkg / ImgBB）
- ⛔ **不删 R2/R4/R5**（drawIntentTool / boardTypography / handActionScheduler 用户裁定有用）
- ⛔ **不把 demo.html 当真相源**（用户明示「demo 页面是测试，错误很多」）
- ✅ **改一测一**：每改完一项立即跑 lint + 浏览器手测
- ✅ **变更留痕**：三件套（PROJECT_STATE + ENGINEERING_LOG + DECISIONS）
- ✅ **真相源优先**：代码 > 文档 > 记忆
- ✅ **画布参数**：一律 import `stepHandoff.js`，禁字面值
