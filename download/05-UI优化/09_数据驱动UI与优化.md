### 1.3 数据驱动 UI 改造

#### 1.3.1 canvasParams 双轨消除（L2-F11 / P1-1）

**当前问题**：UI canvasParams ref 与 handoff canvasParams 并存，用户改 UI 不生效。

**改造方案**：
- 删除 UI canvasParams ref
- 改为 computed 从 handoff 读取
- 用户改 UI 时直接写 handoff（通过 `apiClient.knowledge.refine` 或新增 `apiClient.handoff.update`）

#### 1.3.2 question/topic 命名统一（P1-2）

**当前**：数据层 question / UI 层 topic。
**改造方案**：统一用 question（与 truth/territory-* 对齐）。

#### 1.3.3 zones 死代码清理（P1-3）

**当前**：`canvasParams.zones` 定义但 0 引用。
**改造方案**：删除 zones 定义，改 import `BOARD_LAYOUT` from `boardLayout.js`。

#### 1.3.4 导出与渲染对齐（P1-4）

**当前**：导出 MD 读 UI canvasParams，渲染读 handoff canvasParams → 不一致。
**改造方案**：导出 MD 改读 handoff canvasParams。

#### 1.3.5 bCacheKey 加 canvasParams（L2-F12）

**当前**：缓存键缺 canvasParams → 改参数后命中旧 rows。
**改造方案**：
```javascript
function bCacheKey(handoff, canvasParams) {
  return `b-gen:${hash(handoff.problemText + handoff.problemType + handoff.boardFocus + canvasParams.coordinateMode + ...)}`
}
```
