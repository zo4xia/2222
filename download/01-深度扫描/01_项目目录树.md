## 颜色职责标注的关键发现

1. **🟥 核心运行时代码真相源**：`src/services/stepHandoff.js` 是画布参数唯一真源；`src/agent-b-v2/prompt.js` 是 Agent B 系统提示词唯一真源；`src/agent-b-v2/contract.js` 是五字段合同唯一真源。
2. **🟦 非真相源**：`skills/demo.html`、`handwrite-compare*.html`、`lecture-*.html`、`白板播放器-平行四边形DEMO.html`、`truth/src.zip` 全部为测试/参考，**禁止反推正式口径**（用户原话）。
3. **🟨 文档与代码字段口径**：`doc/DELIVERABLE_API_SPEC.md` 声明 `stats` / `problemText` 根级必填，但 `deliverableStoreHandler.writeDeliverableFile` 从未生成；`KNOWN_ISSUES.md` P0-2 "B 输出解析过于严格" 与 `agentBV2Handler.js:300-336 tryExtractFallbackRows` 软降级存在矛盾（代码已部分修复但文档未同步）。
4. **🟩 数据持久化风险**：`public/pic/` 混存 JPG + MP3，`screenshotStorePlugin` 一律返回 `image/jpeg` 导致 `/pic/audio-*.mp3` 浏览器无法播放；`public/deliverable/current.html` 内容是降级重定向脚本（`handdraw-player.html` 不存在）。
5. **🟪 第三方本地化合规**：所有境外资源（Google Fonts / jsdelivr / unpkg / ImgBB）已被本地化替换；唯一例外 `fontsapi.zeoseven.com`（用户明确允许的国内字体 CDN）。
6. **🟥 后端缺 Vercel Function**：22 个 API 端点只有 6 个有 `api/*.js` Vercel Function，部署到 Vercel 后 16 个端点 404。
