## 图 2 · 主链路时序图（贴题 → 生成 → 导出 → 播放）

```mermaid
sequenceDiagram
    autonumber
    actor User as 👤 用户
    participant FE as 前端 Vue3
    participant Vite as Vite Dev Middleware
    participant H as server Handlers
    participant LLM as 上游 LLM
    participant FS as public/ 持久化
    
    Note over User,FS: 阶段 A · 贴题识别
    User->>FE: 上传图片/输入题文
    FE->>Vite: POST /api/recognition/problem<br/>{imageDataUrl/apiKey/endpoint/model}
    Vite->>H: recognitionHandler.js
    H->>H: 内存缓存命中？(24h/100条)
    alt 缓存命中
        H-->>FE: 200 {ok, result, cached:true}
    else 缓存未命中
        H->>H: selectAgentAKnowledge Top-K
        H->>LLM: requestChatCompletion (60s)
        LLM-->>H: {result, knowledgeAnalysis}
        H->>H: hydrateAgentAKnowledge 回填
        H->>H: writeCache
        H-->>FE: 200 {ok, result, cached:false, knowledgeRetrieval}
    end
    
    Note over User,FS: 阶段 B · 四区规划 + 截图 + handoff
    User->>FE: 点击「规划四标签+网格」
    FE->>FE: planLabelsFromTopic (boardLayout.js)
    FE->>FE: 自动截图 snapdom.toCanvas
    FE->>Vite: POST /api/screenshot<br/>{imageBase64}
    Vite->>H: screenshotStoreHandler
    H->>FS: 写 public/pic/shot-*.jpg
    H-->>FE: 200 {urlPath}
    User->>FE: 点击「确定进入生成表」
    FE->>FE: buildStep1Handoff (stepHandoff.js)
    FE->>Vite: POST /api/handoff<br/>{handoff}
    Vite->>H: handoffStoreHandler
    H->>FS: 写 public/handoff/handoff-*.json<br/>+ current.json
    H-->>FE: 200 {projectCode, filename}
    FE->>FE: emit enter-board-draft → 切到 AgentB 页
    
    Note over User,FS: 阶段 C · Agent B 生成五字段
    User->>FE: 点击「生成」按钮
    FE->>FE: bCacheGet (localStorage 24h)
    alt 缓存命中
        FE-->>FE: 复用旧 rows
    else 缓存未命中
        FE->>Vite: POST /api/agent-b-v2/generate<br/>{handoff, systemPrompt, skillId, canvasParams, temperature}
        Vite->>H: agentBV2Handler.js
        H->>H: normalizeAgentBPromptHandoff 白名单过滤
        H->>LLM: requestChatCompletion (300s OpenAI / 90s Anthropic)
        LLM-->>H: JSON {rows:[...]}
        H->>H: parseAgentBV2Response (contract.js)
        alt 解析成功
            H->>H: validateAgentBV2Rows
            H->>H: normalizeBoard 剥离 startCoord
        else 解析失败
            H->>H: tryExtractFallbackRows 软降级 ⚠️ KNOWN_ISSUES P0-2
        end
        H->>FS: 写 public/board-result/board-result-*.json + current.json
        H-->>FE: 200 {ok, rows, projectCode, filename, usage}
        FE->>FE: applyAgentBV2Timeline (timing.js)
        FE->>FE: bCacheSet
    end
    
    Note over User,FS: 阶段 D · 单行 TTS 合成
    User->>FE: 点击某行 🔊 喇叭
    FE->>Vite: POST /api/tts/synthesize<br/>{text, referenceId}
    Vite->>H: fishAudioHandler
    H->>H: md5 缓存命中？(audio-cache)
    alt 缓存未命中
        H->>LLM: POST api.fish.audio/v1/tts<br/>(多 Key 轮询)
        LLM-->>H: audio buffer
        H->>FS: 写 public/audio-cache/md5.mp3
    end
    H-->>FE: 200 {audioUrl, cached}
    FE->>FE: readAudioDuration (loadedmetadata)
    FE->>FE: 重算时间线 applyAgentBV2Timeline
    
    Note over User,FS: 阶段 E · TTS 保存本地
    User->>FE: 点击「保存本地」
    FE->>Vite: POST /api/tts/save-local
    Vite->>H: fishAudioHandler.saveSpeechLocally
    H->>FS: 写 public/audio/audio-*-stepN.mp3<br/>+ ⚠️ public/pic/audio-*-stepN.mp3 副本
    H-->>FE: 200 {audioUrl, companionPicUrl}
    
    Note over User,FS: 阶段 F · Check Agent C 润色
    User->>FE: 点击「Check Agent」
    FE->>Vite: POST /api/check-agent/check<br/>{currentRows, apiKey, endpoint, model, mode?}
    Vite->>H: checkAgentHandler.js
    alt mode=asr_fast 或 缺 credentials
        H->>H: polishRowsASR 本地降级
    else 远程调用
        H->>H: readCurrentResult 取 handoff
        H->>LLM: requestChatCompletion (25s 超时)
        alt 远程成功
            H->>H: polishRowsASR 二次保障
        else 远程失败/超时/解析失败
            H->>H: polishRowsASR 兜底
        end
    end
    H-->>FE: 200 {ok, rows, changes, checkStatus, note}
    User->>FE: 点击「应用」
    FE->>Vite: POST /api/check-agent/apply<br/>{rows}
    Vite->>H: checkAgentHandler.handleCheckApplyRequest
    H->>FS: 写 board-result-*.original.json 备份<br/>+ 覆写当前 board-result
    H-->>FE: 200 {ok, filename, rows}
    
    Note over User,FS: 阶段 G · 知识点修缮
    User->>FE: 点击「优化确认」
    FE->>Vite: POST /api/knowledge/refine
    Vite->>H: knowledgeRefineHandler
    H->>FS: 写 handoff-*.original.json 备份
    H->>LLM: requestChatCompletion (60s)
    LLM-->>H: 修缮 JSON
    H->>H: 字段级 merge (5 字段)
    H->>FS: 覆写当前 handoff
    H-->>FE: 200 {ok, handoff}
    Note over H,FS: ⚠️ /api/knowledge/revert 分支不可达<br/>(L3-1 BUG，备份永远读不回)
    
    Note over User,FS: 阶段 H · 导出 + 生成交付物
    User->>FE: 点击「导出口播稿 MD」/「要素表」/「分镜表」
    FE->>FE: speechMarkdown.js 生成 MD → 下载
    User->>FE: 点击「生成 HTML 产物」
    FE->>Vite: POST /api/deliverable<br/>{deliverable}
    Vite->>H: deliverableStoreHandler
    H->>H: layoutBoardRows 注入 startCoord
    H->>H: computeRowGroupTimeline 注入 estimatedDurationMs
    H->>H: renderDeliverableHtml ⚠️ 模板缺失必走降级
    H->>FS: 写 deliverable-*.json/.html + current.*
    H-->>FE: 200 {url}
    User->>FE: 点击「打开 HTML 产物」
    FE->>FE: window.open('/deliverable/handdraw-player.html')<br/>⚠️ 404 (L3-2 BUG)
    
    Note over User,FS: 阶段 I · 清理临时文件
    User->>FE: 点击「清理」
    FE->>Vite: POST /api/cleanup
    Vite->>H: cleanupHandler
    H->>FS: 删 5 目录非保留集<br/>⚠️ 误删 *.original.json (L3-6 BUG)
    H-->>FE: 200 {ok, count, bytes, files[]}
```
