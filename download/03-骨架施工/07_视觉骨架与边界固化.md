## 二、CDN 使用五原则落实

### 2.1 五原则定义

| 原则 | 内容 | 项目落实情况 |
|---|---|---|
| **原则 1** | 优先 CDN（资源走 CDN 加速） | ✅ KaTeX / rough.js / snapdom.js 全部本地化或 CDN 备份 |
| **原则 2** | 国内化双备用（境外资源替换为国内 CDN） | ✅ 仅 `fontsapi.zeoseven.com`（用户允许例外）；无 jsdelivr/unpkg/Google Fonts |
| **原则 3** | 版本锁定（package.json caret 锁版本） | ✅ 所有依赖 caret 锁定（如 `vue: ^3.5.39`） |
| **原则 4** | 合规（不引用境外不可达资源） | ✅ `index.html` 已加 `onerror` 优雅降级到系统楷体栈 |
| **原则 5** | 本地化兜底（CDN 失败有本地副本） | ✅ `public/rough.js` + `public/snapdom.js` + `public/katex/*` + `public/fonts/pingfang-qiaomu.ttf`（但字体族无消费者） |

### 2.2 字体加载策略（已落实）

```html
<!-- index.html:46 -->
<link href="https://fontsapi.zeoseven.com/490/main/result.css"
      onload="this.rel='stylesheet'"
      onerror="console.warn('[Font] 板书字体 CDN 加载异常，已降级为系统楷体');"
      rel="preload" as="style" crossorigin />
<noscript>
  <link rel="stylesheet" href="https://fontsapi.zeoseven.com/490/main/result.css" />
</noscript>
```

**CDN 失败降级链**：
1. zeoseven CDN 加载 result.css → LikeJianJianTi 字体可用 ✅
2. CDN 失败 → `console.warn` + 系统楷体栈（`PingFang SC` / `Microsoft YaHei`）兜底 ✅
3. `<noscript>` 标签兜底（JS 禁用时仍能加载）
